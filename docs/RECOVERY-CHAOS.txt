heartbeat schedule. Service configuration uses20s instead of60s to catch the
observed stall before Frigate abandons PLAY. Standalone default remains60s.
Protocol heartbeats and legitimate45s cloud/inbound negotiation are unchanged.
Timeout events now include last video and last incoming traffic ages; candidate
failures use bounded classifications. An in-progress write can delay timer
handling up to10s. Faster detection cannot guarantee faster cloud recovery.

Chaos scope
User authorized connector/Frigate container failures only. No Docker-daemon or
host reboot, camera firmware/reset, router or host-firewall changes. Each fault
has an independent restoration guard and is followed by receiver/frame/recording
progress checks before another fault. Network restoration preserves the exact
connector endpoint IP, aliases and gateway priority; its backend stays attached.
Finite tests verify these cases, not universal recovery under every failure.

configured source address (UDP route/bind inspection without sending packets).

setup. The gate is cancellable by existing signals/global test deadline. It
